# 簡單條碼使用說明

## 版本狀態

目前 GitHub Release 提供的是 Pre-release 測試版本，主要用途是功能測試及收集意見，不是正式上線版本。APK 使用 Debug 金鑰簽署，可能包含尚未完整驗證的功能，升級或重新安裝前請自行確認資料是否仍需要保留。

## 建立條碼

1. 在首頁點選「建立條碼」。
2. 選擇條碼類型。選中的項目會顯示主題色背景、粗體文字及勾選圖示。
3. 輸入方便辨識的條碼名稱。
4. 輸入條碼內容。
5. 確認即時預覽可以正常顯示。
6. 選擇是否在條碼下方顯示原始內容。
7. 點選「建立條碼」。

若內容不符合格式，畫面會顯示錯誤原因，修正後即可重新建立。

## 管理條碼

- 點選首頁條碼卡片可開啟條碼詳細頁。
- 點選星號可將常用條碼加入最愛，最愛項目會優先顯示。
- 使用首頁搜尋欄可以搜尋條碼名稱或內容。
- 在詳細頁點選鉛筆按鈕可以修改條碼。
- 在詳細頁點選垃圾桶按鈕可以刪除條碼。

刪除條碼後，使用該條碼的桌面小工具也會顯示為未選擇狀態。

## 出示條碼

開啟條碼詳細頁後，APP 會暫時提高螢幕亮度並防止螢幕休眠，離開頁面後會恢復原本的亮度設定。

掃描時建議：

- 保持手機畫面乾淨。
- 避免陽光或燈光直接反射螢幕。
- 讓掃描器看見完整條碼及左右白色留白。
- 若無法掃描，可稍微調整手機與掃描器的距離。

## 分享條碼

1. 開啟條碼詳細頁。
2. 點選「分享」。
3. 從 Android 分享面板選擇目標應用程式。

分享內容包含 PNG 條碼圖片、條碼名稱及原始內容。請勿將敏感條碼分享給不信任的對象。

## 加入桌面小工具

### 從 APP 加入

1. 開啟條碼詳細頁。
2. 點選「桌面小工具」。
3. 在系統畫面確認加入小工具。
4. 選擇要顯示的條碼。

### 從桌面加入

1. 長按 Android 桌面空白區域。
2. 點選「小工具」。
3. 找到「簡單條碼」。
4. 將小工具拖曳到桌面。
5. 選擇要顯示的條碼。

小工具可以水平或垂直調整尺寸。條碼會使用名稱以外的可用高度，名稱以小字顯示在條碼下方。小工具使用無外框的白色圓角背景，不會跟隨 App 主題色。為維持掃描成功率，建議至少保留兩格以上的桌面寬度。

## 更換主題

1. 在首頁點選右上角設定按鈕。
2. 選擇晴空藍、薄荷綠、柳橙橘、珊瑚紅、葡萄紫或蜂蜜黃；Hue 滑桿會移至對應色相。
3. 若要自訂色彩，拖曳自訂色塊右側的 Hue 彩色滑桿。左側圓形色塊會顯示目前顏色。
4. 點選自訂色塊可重新套用目前的自訂色彩。
5. 預設色、自訂色與顯示模式都會立即套用，不需要額外儲存。

設定頁最上方的顯示模式提供：

- 跟隨系統
- 淺色
- 深色

條碼本身固定使用高對比黑色線條及白色背景，避免主題色降低掃描辨識率。

## 資料與隱私

- 所有條碼及設定都儲存在 APP 的本機資料中。
- 移除 APP 或清除 APP 資料會刪除已建立的條碼。
- 目前版本沒有雲端同步或匯出備份功能。
- APP 不會將條碼上傳到伺服器。

## 常見問題

### 小工具沒有顯示條碼

請點選小工具重新進入 APP，確認原本選擇的條碼仍存在。若條碼已刪除，請移除小工具後重新加入並選擇條碼。

### 找不到加入小工具的按鈕

部分 Android 啟動器不支援由 APP 直接要求釘選小工具。請長按桌面空白處，從系統的小工具清單加入。

### APK 無法安裝

請確認裝置為 Android 8.0 以上，並允許目前使用的瀏覽器或檔案管理器安裝未知來源應用程式。若已安裝使用不同簽章的版本，可能需要先移除舊版本。

### 條碼無法掃描

請確認內容符合所選格式，並放大桌面小工具或改用 APP 詳細頁顯示。某些掃描器只支援特定條碼格式。
